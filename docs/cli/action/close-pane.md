# `tos action close-pane`

Close a pane

```
tos action close-pane [OPTIONS]
```

Also: `close`.

## Options

| Option | |
|---|---|
| `-p, --pane-id <PANE_ID>` | The pane, e.g. terminal_3 or 3 (default: the focused pane). |
