# `tos action close-tab`

Close a tab and everything in it

```
tos action close-tab [OPTIONS]
```

## Options

| Option | |
|---|---|
| `-t, --tab-id <TAB_ID>` | The tab's id, as `list-tabs` shows it (default: the active tab). |
