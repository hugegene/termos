# `tb action edit-scrollback`

Open a pane's scrollback in the editor

```
tb action edit-scrollback [OPTIONS]
```

## Options

| Option | |
|---|---|
| `-p, --pane-id <PANE_ID>` | The pane, e.g. terminal_3 or 3 (default: the focused pane). |
| `-a, --ansi` | Accepted for zellij; the editor gets plain text. |
