# `tos action move-pane-backwards`

Swap a pane with the previous pane

```
tos action move-pane-backwards [OPTIONS]
```

## Options

| Option | |
|---|---|
| `-p, --pane-id <PANE_ID>` | The pane, e.g. terminal_3 or 3 (default: the focused pane). |
