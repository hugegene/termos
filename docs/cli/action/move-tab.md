# `tb action move-tab`

Move a tab one place left or right

```
tb action move-tab [OPTIONS] <DIRECTION>
```

## Arguments

| Argument | |
|---|---|
| `<DIRECTION>` | Values: `left`, `right`. |

## Options

| Option | |
|---|---|
| `-t, --tab-id <TAB_ID>` | The tab's id, as `list-tabs` shows it (default: the active tab). |
