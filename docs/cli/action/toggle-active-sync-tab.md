# `tb action toggle-active-sync-tab`

Type into every pane of a tab at once, or stop

```
tb action toggle-active-sync-tab [OPTIONS]
```

## Options

| Option | |
|---|---|
| `-t, --tab-id <TAB_ID>` | The tab's id, as `list-tabs` shows it (default: the active tab). |
