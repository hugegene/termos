# `tos action toggle-docs`

Show a tab's docs pane, or hide it if it's showing (tos)

```
tos action toggle-docs [OPTIONS]
```

## Options

| Option | |
|---|---|
| `-t, --tab-id <TAB_ID>` | The tab's id, as `list-tabs` shows it (default: the active tab). |
