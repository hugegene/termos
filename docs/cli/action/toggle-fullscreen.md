# `tb action toggle-fullscreen`

Show a pane alone in its tab, or stop

```
tb action toggle-fullscreen [OPTIONS]
```

Also: `zoom`.

## Options

| Option | |
|---|---|
| `-p, --pane-id <PANE_ID>` | The pane, e.g. terminal_3 or 3 (default: the focused pane). |
