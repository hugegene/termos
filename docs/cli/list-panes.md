# `tb list-panes`

List the session's panes

```
tb list-panes [OPTIONS]
```

## Options

| Option | |
|---|---|
| `-s, --session <SESSION>` | Session name (default: the session you're in, else "main"). |
| `-j, --json` | Print JSON. |
| `-a, --all` | Every column. |
