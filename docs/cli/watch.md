# `tos watch`

Show a running session read-only (zellij's `watch`); q or Ctrl+C stops watching

```
tos watch [NAME]
```

Also: `w`.

## Arguments

| Argument | |
|---|---|
| `[NAME]` | Session name (default: the session you're in, else "main"). |
