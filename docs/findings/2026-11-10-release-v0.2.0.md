# Release v0.2.0 (termos, command `tos`): the build and the install, including the upgrade from `tb`

## Question

Does the first release under the new names ([rename plan](../plans/2026-11-10-rename-to-termos.md)) build
and install? It covers `tos-<target>.tar.gz`, `TOS_*` and the `termos` folders. And does the one-liner
upgrade a machine that has `tb 0.1.1`? The [first release finding](2026-11-10-first-release.md) left upgrades
untested, and the distribution plan's README and installer claims depend on it.

## Method

On 2026-11-10. Tag `v0.2.0` on `2b8043e`, pushed by the user, built by release run `42778272141`. The local
machine is Ubuntu 24.04.5, x86_64, with Docker.

```sh
gh run view 42778272141 -R hugegene/termos --json jobs --jq '.jobs[] | "\(.name): \(.conclusion) \(.startedAt) \(.completedAt)"'
gh release view v0.2.0 -R hugegene/termos --json name,assets

# The upgrade: <scratch>/real holds tb 0.1.1, installed from v0.1.1 earlier the same day
curl -fsSL https://github.com/hugegene/termos/releases/latest/download/install.sh | TOS_INSTALL_DIR=<scratch>/real sh

# A clean system
docker run --rm ubuntu:22.04 sh -c 'apt-get install curl ca-certificates && curl -fsSL …/install.sh | sh &&
  tos attach -b demo && tos ls && tos kill demo && tos ls && ls -d /root/.local/state/termos'
```

## Conclusions

- **v0.2.0 builds and installs** under the new names. The one-liner now gives `tos 0.2.0`, and the files are
  about the same size as v0.1.1's.
- **Upgrading from `tb` works:** `tos` installs next to the old `tb`, which is kept (a running `tb` server
  still needs it), and the installer says how to end its sessions and remove it.
- **A new install keeps its state in `~/.local/state/termos`.**
- **Still unknown:**
  - **The move from `tb` to `termos` folders on a real machine.** It was only tried with a throwaway `HOME`
    ([rename plan](../plans/2026-11-10-rename-to-termos.md)). The user's own switch-over will be the first.
  - **Upgrading from one `tos` to the next.** There's only one `tos` release.
  - **The macOS build by hand on a Mac,** as before.
