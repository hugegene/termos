# Plan: a doc for each `tb` command

**Status:** built (2026-11-05) · **Date:** 2026-11-05 · **Related:** [docs/cli.md](../cli.md) (the extension API's
overview), [CLI extension plan](2026-11-05-cli-extensions.md)

## Decision

Every `tb` command gets its own page, **generated from the command definitions** that also produce
`tb … --help`, so the page and the help always agree.

- **Where:**
  - `docs/cli/<command>.md` for top-level commands (`attach.md`, `subscribe.md`, …)
  - `docs/cli/action/<action>.md` for `tb action …` (`new-pane.md`, `list-tabs.md`, …)
  - `docs/cli/README.md`: an index of every command with its one-line description
- **On each page:**
  - the description and usage
  - arguments and options: their help, allowed values, defaults and aliases
  - examples, where the command has them
  - a link back to [docs/cli.md](../cli.md) for ids, JSON fields, events and config
- **Kept current by a test.**
  - `cargo test` renders every page and compares it with `docs/cli/`. Any difference fails, and the
    failure names the stale pages and the command that rewrites them:
    `TB_UPDATE_DOCS=1 cargo test -p tb --bin tb cli_docs`.
  - The same run deletes pages of commands that no longer exist.
  - Pages aren't edited by hand. Text changes go into the help text in `crates/tb/src`, and examples into
    the commands' `after_long_help`, which `tb … --help` shows as well.
- **`docs/cli.md` stays** as the overview of the concepts that span commands, linking to the index.
- **Examples** start with the commands extensions and users reach for most:
  - `attach`, `run`, `subscribe`
  - `new-tab`, `new-pane`, `list-tabs`, `list-panes`
  - `send-keys`, `write-chars`, `resize`, `dump-screen`, `set-pane-color`, `set-status`, `go-to-tab-name`

## Options considered

| Option | Verdict |
|---|---|
| Hand-written pages | ❌ About 80 pages that drift from the code with every change |
| A man page per command (`clap_mangen`) | ❌ A new crate, which needs a download; Markdown reads on GitHub and in the repo |
| **Generated Markdown, checked by a test** | ✅ No new crate (clap describes its own commands); can't drift |
