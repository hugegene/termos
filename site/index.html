What it does

Sessions that come back

Tabs, split panes, scrolling and search, with zellij's keys and tmux's. Close the window or reboot: tos brings back the layout, the folders and the finder.

A terminal file finder

Previews PDFs, images, video frames, Word, PowerPoint, spreadsheets, Markdown and HTML, right in the terminal. Edits text in Neovim and CSV in a grid.

AI agents side by side

Run Claude Code or any agent in a tab, with the finder next to it. Its files show up straight away. prbot opens a Claude tab for each pull request that needs you.

Quick start

  1. tos starts a session, or goes back to the one running.
  2. Ctrl+t f opens the finder on the folder you're in. The arrows move; → focuses the preview.
  3. Enter in the preview edits: Ctrl+s saves, Ctrl+e closes. o opens any file in its app.
  4. Ctrl+t n opens a new tab, for a shell, Claude Code or anything else.
